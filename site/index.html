Reads, never marks as read

Mail is opened over IMAP in read-only mode. Nothing is marked as read, moved or deleted, so your inbox looks exactly as you left it.

Your inbox is not training data.

Most briefing apps read your mail on their servers. This one reads it on your laptop, writes there, and keeps it there.

  • Runs offline. Planes, trains and bad hotel Wi-Fi are all fine.
  • $0 per morning. No usage meter ticking while you sleep.
  • Nobody can change the terms. The model is a file on your disk. No one can reprice it, retire it or rewrite its policy overnight.

Your first edition in five commands.

Clone it, point it at your inbox, and print today's paper. Then let cron deliver one every morning.

  • A laptop that can run ollama
  • Python with uv
  • An app password for your mail, if you want your inbox in it
Terminal 
brew install ollama && ollama pull gemma4:e4b
git clone https://github.com/mohamedaminehamdi/the-localhost-times
cd the-localhost-times && cp .env.example .env
uv run localhost-times --list   # see what's switched on
uv run localhost-times          # print today's edition
crontab: every morning at 7 
0 7 * * * cd ~/the-localhost-times && uv run localhost-times
